# OP演出3種のシャッフル表示

## 目的

トップページの初回訪問で、現行OP、候補1、候補2のうち1本を等確率で表示する。同じタブ内では選ばれた演出を固定し、ロゴから再再生しても同じ演出を見せる。

## 対象演出

- 現行OP: `site/src/components/motion/OpSplash.tsx` の約4.8秒の紙片カウントダウン。
- 候補1: 保存済み演出案の `候補1/v2.html` にある「開幕前」モード。数字の紙片からロゴへ変わる約3.4秒の演出。
- 候補2: 保存済み演出案の `英語を修正したらよさそう,候補2/countdown.html`。赤・黄・青の学科モチーフ、数字、黄色い紙のワイプ、ロゴへ続く約4秒の演出。直近のワイプ修正を含む版を移植元にする。

試作ページの再生・シーク・日数入力などの開発用UIは取り込まず、演出だけをサイトへ移植する。

## 動作

1. トップページ初回表示時、`op-seen` がなく、動きを減らす設定や低速回線によるスキップ条件にも該当しなければ、3種から等確率で1種を抽選する。
2. 抽選結果を別の `sessionStorage` キーに保存する。再生完了後も残し、同じタブ内のロゴからの再再生では保存済みの演出を使う。
3. `op-seen` による初回のみ表示、スキップ、ロゴからの再再生、事前カバー解除、終了時のフェードアウトは現在の動作を維持する。各演出固有の所要時間で終了させる。
4. `sessionStorage` が利用できない場合は、ページ上のOPコンポーネントが生きている間は選択を保持する。初回表示そのものは妨げない。
5. 開催日までの日数は既存と同じ日本時間基準で算出する。開催当日用の別演出は今回の対象外とし、現在の日数下限も変更しない。

## 実装境界

`OpSplash` が抽選、セッション制御、共通のスキップ・終了処理を担当する。各OPは独立した演出コンポーネントにして、共通の再生開始と終了時間だけを親に渡す。現行OPの見た目は変更しない。候補1・2の素材はサイト内の `public/op/` など既存の素材配置に合わせ、試作フォルダへの実行時参照は残さない。既存の未コミット差分を保持し、重なる箇所は差分を確認してから編集する。

## 検証

- 抽選が3種とも選べること、同じタブの再再生で種類が変わらないこと、別セッションでは再抽選されること。
- 各演出の自動終了とスキップ、低減モーション・低速回線条件、初回のみ表示。
- 375pxを先に、次にPC幅で各演出の見切れ・素材読込・切り替えを確認する。候補2では黄色いワイプ後に数字が再露出しないことを確認する。
- `site/` で `npm run check` と関連E2Eを実行する。

## 今回しないこと

演出選択UI、確率の重み付け、当日専用OP、トップページ以外での自動再生、試作ページ自体の機能変更。
