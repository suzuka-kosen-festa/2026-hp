# 当日写真OP Implementation Plan

**Goal:** ユーザーが除外した15件を取り除いた固定55件を、ランダムに貼ってロゴへつなぐ。
**Architecture:** Firebaseへアクセスせず、取得済み画像からWebPアトラスを作る。React/WAAPIで55枚の写真カードを遠くから貼り付け、ずり落ちて背後のロゴが現れる6秒の演出を作る。
**Tech Stack:** Astro、React、CSS、Web Animations API。依存追加なし。

## 現在の演出（2026/10/31追加変更）

最新の確認: 「遠くから」は写真の飛距離ではなく、カメラを引いて全体を見る意味。飛行の位置・回転・拡大率・イージングは、最初の貼ってずり落ちる版（65px/-110px、scale1.65）へ戻す。写真群とロゴを含むシーン全体を0.72倍で表示する。「貼るのをもっとゆっくり」のテンポ（1枚500ms・開始間隔38ms）は保ち、全体6秒と落下の速度も維持する。

ユーザーの「もっと勢いよく、適当に写真を貼ってずり落ちて切り替える」に従い、ロゴへのマスク・ズームを使わない。採用55件を1枚ずつランダム配置し、約2.6秒で叩き付けるように貼る。3.1秒から角度を変えながらずれ、少し引っ掛かってから時間差で落下し、背後の完成ロゴを見せる。全体6秒。

検証: 旧ビルドで55枚の期待値に対し120枚が表示されるFAILを確認後に実装。5秒版のhome/gallery 31件PASS、npm run check PASS、git diff --check PASS。375/1280pxの貼付・滑り・完成ロゴをPlaywrightで撮影し、例外0件、スキップと再生成功を確認。証跡は一時フォルダー`festival-op-slip-qa`。未コミット・未公開。

## 決定済みの仕様

- 除外番号: 7,2,5,11,24,23,30,35,36,37,38,39,42,44,48。残り55件を固定で採用。
- 再生ごとに配置・角度・貼付順・落下順をシャッフル。遠くから写真を貼る→ずり落ちる→完成ロゴ、全体6秒。
- 開催前は従来OP、10/31 0:00〜11/2 0:00 JSTだけ当日OP、終了後はOPなし。
- 初回のみ自動再生。開催前と当日で既読を分ける。スキップ、ロゴからの再生、低減モーション、通信失敗に対応。
- galleryに明示的な試聴ボタンを追加。コミット・公開は指示を受けてから。
