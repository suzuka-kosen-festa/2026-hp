# MAP-only implementation plan

> **For agentic workers:** Use superpowers:executing-plans inline. ユーザーの継続指示に従い、再承認待ちは設けない。

**Goal:** 人間が配置したFigmaの素材で会場図を表示し、文字一覧からも同じ案内に進める。
**Architecture:** Astroで図と一覧を静的生成する。MAP専用JSONは座標・既存企画ID・会場対応と確定した表記差を持ち、企画の内容は既存entriesから取得する。校内図はExcelの教室区画とFigmaの棟配置を組み合わせ、教室別一覧を併記する。
**Tech Stack:** Astro、素のCSS、最小のブラウザスクリプト、Playwright。
**Spec:** docs/requirements.md §3.4、docs/superpowers/specs/2026-10-02-map-ux-design.md。後から指定されたMAP-only方針を優先する。

最新の状態は[実装済みのタスクと未確認の品質評価](#実装済みのタスクと未確認の品質評価を分ける2026-10-09)と[提出候補一覧](../../map-submission-files.json)を参照してください。以下の44・45・52件などの検証記録は各工程の履歴で、現在のMAPテストは53件です。
