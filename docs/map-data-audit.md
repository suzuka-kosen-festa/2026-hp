## 調査時の方針：情報の正は基本的にFigma

2026-10-07のユーザー指定により、MAPの情報・配置は基本的にFigmaを正とします。参照専用パンフは企画名・番号・会場、編集用マップは人間が決めた構成・配置の根拠です。ユーザーの直接の訂正を優先し、明示的な保留は維持します。以下のJSON集計・表示名・未入力の会場は調査時点のデータの記録であり、Figmaより正しいという意味ではありません。Figmaで分かることを一件ずつ聞き直さず、資料にない情報や解消できない矛盾だけを確認します。
